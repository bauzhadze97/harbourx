Seeds a test account into this browser so the interface renders without a PHP server. For looking at the design only.

What will not work here Signing in, two-factor, support tickets, converting, withdrawing and AML — all of those are PHP endpoints, and a static server hands back their source instead of running them. For the working app you need PHP; see README.txt.
